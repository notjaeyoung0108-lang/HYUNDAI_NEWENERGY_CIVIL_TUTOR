# 1-0. 뉴에너지 토목은 무엇을 인계하는가

## 이 Flow가 답하는 질문
> 토목의 완료는 콘크리트를 다 쳤다는 뜻일까?

## 전체 그림
```text
설계조건 확인 → 작업면 준비 → 구조물 시공 → 검사·기록 → 기계·전기 인계 → 시운전 지원
```

## 왜 이 순서인가
원전 보조건물, 기기기초, 매입판, 관통부와 배수시설은 후속 설비가 놓일 조건을 만든다. 설비 형식이 바뀌면 기초 하중·앵커 위치·관통부도 함께 검토해야 한다. 배관 용접을 직접 승인하는 직무는 아니어도 배관 지지대와 접근 공간, 시운전 인계일에 미치는 영향은 설명해야 한다.

## 현장에 대입하면
기기기초를 타설했지만 앵커 실측 기록이 없다면 설치팀은 기준 위치를 확신할 수 없다. 작업 실적과 인계 가능한 실적을 구별한다.

## 다음 단계로 넘기는 것
기기 하중표와 승인도면의 개정번호, 앵커 실측 성과, 미결사항 목록

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
콘크리트 수량만 집계하면 설비 설치를 시작할 수 없는 기초도 완료로 잡힌다.
