# 1-2. 주공정과 여유시간을 계산하는 순서

## 이 Flow가 답하는 질문
> 작업이 10일 늦으면 준공도 반드시 10일 늦는가?

## 전체 그림
```text
선후행 확인 → 전진계산(ES·EF) → 후진계산(LS·LF) → 총여유 → 변경 후 재계산
```

## 왜 이 순서인가
ES는 가장 빠른 시작, EF=ES+기간이다. 선행 작업이 여럿이면 EF의 최댓값을 취한다. 끝에서 역산할 때 LF는 후속 LS의 최솟값이고 LS=LF−기간이다. 총여유 TF=LS−ES다. 모든 선행조건이 끝나야 합류점에서 출발할 수 있다. 기간 0인 더미 화살표도 선후행을 강제한다.

## 현장에 대입하면
A 30일과 B 40일을 모두 기다리는 C는 30일째 시작할 수 없다. 시작은 40일째다. 기존 주공정만 줄이면 다른 경로가 새 주공정이 될 수 있다.

## 다음 단계로 넘기는 것
작업별 기간·선후행 목록, 기준 공정표, 변경 공정표, 여유시간 계산표

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
병렬 작업의 지연일을 단순 합산하지 않는다. 경로별 종료일의 최댓값으로 준공일을 구한다.
