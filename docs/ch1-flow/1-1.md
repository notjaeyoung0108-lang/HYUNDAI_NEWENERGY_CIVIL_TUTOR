# 1-1. 설계에서 시공·검측·인계까지

## 이 Flow가 답하는 질문
> 어느 확인이 끝나야 다음 작업으로 넘어갈 수 있는가?

## 전체 그림
```text
설계도서 → 시공계획·검사계획 → 자재 승인 → 작업 전 확인 → 시공 → 검사 → 인계
```

## 왜 이 순서인가
도면은 위치와 형상을, 시방서는 성능과 검사조건을 설명한다. 서로 충돌하면 계약상 문서 우선순위와 설계 회신으로 해소한다. Hold Point는 검사계획에서 정한 진행 보류 지점이다. 승인권자의 해제 없이 넘어가지 않는다. Witness Point와 같다고 생각하면 안 된다.

## 현장에 대입하면
타설 전 철근·피복·매입물 검사와 도면 개정 확인이 끝나야 한다. 뒤늦게 앵커가 틀렸음을 발견하면 기초와 설치 공정이 함께 영향을 받는다.

## 다음 단계로 넘기는 것
승인도면, ITP(검사·시험계획), 검사 요청서, 검사 결과와 보류 해제 기록

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
서명이 있다는 이유만으로 실제 부적합을 적합으로 취급하지 않는다. 오류를 발견하면 이력과 정정 사유를 남긴다.
