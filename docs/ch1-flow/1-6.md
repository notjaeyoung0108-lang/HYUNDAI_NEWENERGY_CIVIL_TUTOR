# 1-6. 설계변경과 부서 간 합의

## 이 Flow가 답하는 질문
> 발주처의 좋은 제안을 바로 시공해도 되는가?

## 전체 그림
```text
요청 기록 → 기술 적합성 → 수량·원가·공기 영향 → 권한자 승인 → 도서 개정 → 시공
```

## 왜 이 순서인가
새 자재가 더 좋다는 주장만으로 설계 적합성은 확보되지 않는다. 재료 호환성, 구조성능, 시공성, 검사기준과 유지관리 조건을 먼저 확인한다. 품질팀은 합격 조건, 공정팀은 인계일, 공무팀은 비용·변경조건을 같은 표에서 합의한다.

## 현장에 대입하면
탄소섬유는 외피 보강 방식이다. 떨어져 나간 콘크리트 단면과 손상된 바탕을 회복하는 과정을 자동으로 대체하지 않는다. 설계자가 동등성을 검토한 뒤 변경 여부를 판단한다.

## 다음 단계로 넘기는 것
기술질의(RFI), 설계변경 요청, 비용·공기 비교, 발주처 회신과 개정도면

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
장래 계약 약속을 확정 수익처럼 처리하거나 구두 요청만으로 자재를 바꾸지 않는다.
