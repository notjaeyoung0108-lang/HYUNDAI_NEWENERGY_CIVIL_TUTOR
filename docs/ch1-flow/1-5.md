# 1-5. 부적합 발견에서 시정조치까지

## 이 Flow가 답하는 질문
> 검사에 이미 서명했다면 하자를 어떻게 처리하는가?

## 전체 그림
```text
사용·설치 보류 → 식별·격리 → 사실 보고·NCR → 기술평가 → 승인된 처분 → 재검사 → 종결
```

## 왜 이 순서인가
NCR은 부적합 보고서다. 결함 위치·규격·발견시점과 이미 시공된 범위를 특정한다. 처분은 재작업, 보수, 반품 등 승인된 절차로 정하며 현장 담당자가 임의로 적합 판정을 만들지 않는다. 원인 제거와 재발 방지는 해당 결함 하나의 보수와 별개다.

## 현장에 대입하면
기기 검수 누락을 알게 되면 기존 서명 원본을 지우지 않고 오류 발견과 정정 이력을 남긴다. 외관상 보이지 않거나 사고확률이 낮다는 이유로 설치를 진행하지 않는다.

## 다음 단계로 넘기는 것
자재 식별번호, 검사 원본, 부적합 범위, 처분 승인, 재검사 결과, 재발방지 담당자

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
미국 NRC 품질보증 자료는 부적합 관리 원리를 설명하는 참고다. 국내 개별 현장에 그대로 적용되는 법이나 계약으로 단정하지 않는다.
