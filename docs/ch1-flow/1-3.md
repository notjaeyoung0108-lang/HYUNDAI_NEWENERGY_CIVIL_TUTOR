# 1-3. 공기단축과 총비용 비교

## 이 Flow가 답하는 질문
> 하루를 줄이는 비용보다 하루 늦는 비용이 작으면 무엇을 해야 하는가?

## 전체 그림
```text
비교기준 통일 → 직접 증분비 → 지연손실 → 재작업 위험 → 실행가능성 → 승인
```

## 왜 이 순서인가
총 증분비용은 추가 재료·노무·검사비, 촉진비, 지연손실을 같은 단위로 합친다. 기존에 지출한 비용은 양안에 동일하면 중복 반영하지 않는다. 경제적으로 싼 지연안과 계약 준수안은 구별해서 제시한다. 계약이나 안전조건 위반을 단순한 유료 선택지처럼 취급하지 않는다.

## 현장에 대입하면
10일 지연 손실이 10억원이고 공기단축비가 20억원이면 직접비만으로는 지연안이 10억원 유리하다. 그러나 준공 준수 요구와 수주 신뢰도까지 검토해야 최종 결정이 된다.

## 다음 단계로 넘기는 것
원가 비교표, 단축 가능 작업과 한도, 계약상 준공조건, 승인 필요 예산

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
수주금액을 이익으로 더하지 않는다. 200억원 공사를 받을 가능성은 200억원 이익이 아니다.
