# 1-4. 부족한 자재를 배분하는 순서

## 이 Flow가 답하는 질문
> 모든 부서가 급하다고 하면 누구에게 먼저 주는가?

## 전체 그림
```text
검수된 재고 → 필수 안전 수요 → 착수 최소량 → 시점별 잔량 → 준공손실 → 배분 승인
```

## 왜 이 순서인가
수요의 크기뿐 아니라 분할 착수 가능 여부를 확인한다. 2개월치를 한꺼번에 받아야 시작하는 부서에 1개월치를 주면 재고는 줄고 실적은 생기지 않는다. 자재량과 작업기간, 납품 간격은 서로 다른 축이다.

## 현장에 대입하면
입고량 3개월치 중 안전 구조물에 1개월치를 배정하면 2개월치가 남는다. 이를 주공정에 주는 안과 추가계약에 몰아주는 안을 월별 시간축으로 비교한다.

## 다음 단계로 넘기는 것
차수별 검수·재고표, 부서별 소요량과 착수조건, 배분일·후속입고일·완료일

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
월별 손실을 계산하면서 월을 일로 바꾸는 가정을 빠뜨리지 않는다. 교육용 30일과 실제 계약상 달력일은 다르다.

## 스스로 확인
1. 이 Flow에서 확인이 빠지면 후속 공정이 가장 크게 영향을 받는 칸은 어디인가?
2. 위 사례에서 사실로 주어진 것과 추가로 확인해야 할 것을 나눠 설명하라.
3. 담당자가 오늘 남겨야 할 기록을 세 가지 말하라.
