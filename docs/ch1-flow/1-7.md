# 1-7. 20분 준비·5분 발표의 구조

## 이 Flow가 답하는 질문
> 계산과 판단을 짧은 발표 안에 어떻게 담는가?

## 전체 그림
```text
조건 분류 → 핵심 계산 → 가능한 대안 → 결론 → 실행·재확인
```

## 왜 이 순서인가
20분 준비라면 조건 읽기 4분, 계산 6분, 대안 비교 5분, 발표 정리 5분으로 연습한다. 10분 준비 문제는 각각 2·3·3·2분으로 줄인다. 발표는 결론 30초, 사실과 계산 90초, 비교 90초, 실행 60초, 남은 확인 30초로 구성한다.

## 현장에 대입하면
“단면재생안을 우선 검토합니다. 보수면적 135㎡, 체적 4.05㎥이며 주어진 소수일 계산으로 총 5.25일입니다. 준공 영향 2.25일은 남아 있으므로 이를 숨기지 않고 승인권자에게 함께 제시하겠습니다.”

## 다음 단계로 넘기는 것
한 줄 결론, 계산식, 대안 비교표, 담당자·시점·재검사 조건

| 담당 | 판단과 산출물 |
|---|---|
| 공사 | 작업 조건·실물·다음 공종에 넘길 상태를 확인한다. |
| 공무 | 수량·비용·기간과 변경·통지 근거를 기록한다. |
| 품질·설계 | 검사기준과 기술적 처분·변경 승인조건을 확인한다. |

## 자주 틀리는 지점
수치가 모호하면 가정을 먼저 말하고 대체 해석 결과를 제시한다. 미확정 정보를 확정 답처럼 외우지 않는다.

## 스스로 확인
1. 이 Flow에서 확인이 빠지면 후속 공정이 가장 크게 영향을 받는 칸은 어디인가?
2. 위 사례에서 사실로 주어진 것과 추가로 확인해야 할 것을 나눠 설명하라.
3. 담당자가 오늘 남겨야 할 기록을 세 가지 말하라.
