# 2-02. 콘크리트 타설·양생·품질 확인

## ① Flow 도식
```text
배합·자재 승인 → 타설계획 → 철근·매입물 검측 → 반입검사 → 타설·다짐 → 양생 → 검사·인계
```

## ② 왜 이 순서인가
콘크리트는 타설과 동시에 품질이 결정되는 부분이 크다. 조밀한 철근 사이로 재료가 지나갈 수 있는지와 다짐 접근성을 먼저 확인한다. 강도를 만족해도 공극·두께 부족·피복 부족은 별도 평가 대상이다.

## ③ Hold Point
타설 전 검사와 타설 중 부적합 발견 시 진행 판단. 거푸집 해체와 하중 도입도 승인 조건을 확인한다.

## ④ 정상 판정 기준
배합·반입·다짐·양생 기록과 요구 성능이 연결되고 표면 및 치수 검사가 완료된다.

## ⑤ 다음 공종에 넘기는 것
타설구획, 배치·시간, 시험체·강도, 양생 상태, 표면 결함 지도

## ⑥ 이상의 신호와 그 의미
벌집 모양 공극, 박리, 두께 부족은 덧바르기 전에 깊이·면적·구조 영향을 확인해야 하는 신호다.

| 확인 축 | 스스로 물어볼 질문 |
|---|---|
| 실물 | 도면·규격과 실제 상태가 같은가? |
| 기록 | 누가 무엇을 근거로 확인했는가? |
| 후속 공정 | 어떤 확인이 끝나야 넘길 수 있는가? |

## 판단 연습
1. 이 순서에서 한 칸을 생략하면 어떤 결함을 놓치는가?
2. 공사·공무·품질 담당자에게 각각 무엇을 요청할 것인가?
3. “공정이 급하다”는 조건이 붙어도 유지해야 할 인계 조건은 무엇인가?
