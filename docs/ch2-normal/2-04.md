# 2-04. 탄소섬유 보강의 성립 조건

## ① Flow 도식
```text
구조평가 → 보강설계 → 손상 단면·바탕 복구 → 표면 준비 → 수지·섬유 시공 → 양생 → 검사
```

## ② 왜 이 순서인가
FRP 보강은 섬유와 수지, 콘크리트 사이에서 힘이 전달되어야 성립한다. 바탕이 약하거나 부착이 확보되지 않으면 재료 강도만 높아도 의도한 보강성능을 얻기 어렵다. 설계상 필요한 단면 복구와 보강은 구분한다.

## ③ Hold Point
건전한 바탕과 복구 범위 확인, 섬유 방향·겹침·정착 조건 확인, 양생 후 검사

## ④ 정상 판정 기준
설계가 정한 바탕·부착·정착과 환경·내화·보호 조건, 재료 적용범위를 만족한다.

## ⑤ 다음 공종에 넘기는 것
보강설계 승인, 바탕 검사, 시공 환경·배합·재료 이력, 양생·부착 검사, 유지관리 항목

## ⑥ 이상의 신호와 그 의미
박리된 콘크리트를 덮어서 감추는 시공은 단면재생의 대안이 아니다. 문제의 속도·비용 표는 기술적 동등성을 입증하지 않는다.

| 확인 축 | 스스로 물어볼 질문 |
|---|---|
| 실물 | 도면·규격과 실제 상태가 같은가? |
| 기록 | 누가 무엇을 근거로 확인했는가? |
| 후속 공정 | 어떤 확인이 끝나야 넘길 수 있는가? |
