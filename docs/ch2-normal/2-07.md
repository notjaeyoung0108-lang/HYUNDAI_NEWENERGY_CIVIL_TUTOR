# 2-07. 공정 인계와 시운전 준비

## ① Flow 도식
```text
공종별 완료조건 → 검사기록 확인 → 미결사항 분류 → 시스템별 인계 → 시운전 허가
```

## ② 왜 이 순서인가
공종이 끝나는 순서와 시스템이 작동할 수 있는 순서는 다를 수 있다. 일부 토목 작업이 남아도 가능한 인계와, 한 개의 미결만으로도 막히는 인계를 구별한다. 허용 여부는 담당 조직의 승인 절차로 정한다.

## ③ Hold Point
안전·품질상 필수 미결사항이 남은 상태의 임의 인계 금지

## ④ 정상 판정 기준
작업·검사 완료, 접근·방호 조건, 도면과 실물 일치, 인계 권한자의 승인

## ⑤ 다음 공종에 넘기는 것
준공도, 검사·시험 성적, 미결사항 담당자와 기한, 인계 확인서

## ⑥ 이상의 신호와 그 의미
시운전 여유 3일에 4일짜리 보수가 생기면 최소 1일 영향을 계산한다. 검사 실패와 승인 지연은 추가 위험이다.

| 확인 축 | 스스로 물어볼 질문 |
|---|---|
| 실물 | 도면·규격과 실제 상태가 같은가? |
| 기록 | 누가 무엇을 근거로 확인했는가? |
| 후속 공정 | 어떤 확인이 끝나야 넘길 수 있는가? |

## 판단 연습
1. 이 순서에서 한 칸을 생략하면 어떤 결함을 놓치는가?
2. 공사·공무·품질 담당자에게 각각 무엇을 요청할 것인가?
3. “공정이 급하다”는 조건이 붙어도 유지해야 할 인계 조건은 무엇인가?
