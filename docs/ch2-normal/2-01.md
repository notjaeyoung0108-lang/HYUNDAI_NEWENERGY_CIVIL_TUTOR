# 2-01. 기초·매입물·앵커 인계

## ① Flow 도식
```text
하중·지반·도면 확인 → 굴착저면 검측 → 철근·앵커·매입물 → 타설 전 검사 → 타설·양생 → 실측 → 설비 인계
```

## ② 왜 이 순서인가
기기 하중과 앵커 배열은 설비 설치의 기준이다. 설계 개정 확인 전에 철근을 조립하면 간섭을 뒤늦게 발견한다. 타설 후에는 내부 매입물 위치를 직접 볼 수 없으므로 사전 검측이 필요하다.

## ③ Hold Point
타설 전 철근·피복·앵커·접지·관통부 검측. 구체적인 보류 지점은 승인된 ITP로 확정한다.

## ④ 정상 판정 기준
승인도면의 위치·레벨·허용오차와 시험계획의 콘크리트 요구성능을 충족한다. 임의의 공통 허용오차를 만들지 않는다.

## ⑤ 다음 공종에 넘기는 것
앵커 좌표·레벨 실측, 콘크리트 시험·양생 기록, 매입물 검사, 미결사항과 하중 도입 가능 조건

## ⑥ 이상의 신호와 그 의미
앵커가 볼트구멍과 맞지 않으면 억지로 가공하기 전에 기준점·도면·실측 오차와 설계 영향을 확인한다.

| 확인 축 | 스스로 물어볼 질문 |
|---|---|
| 실물 | 도면·규격과 실제 상태가 같은가? |
| 기록 | 누가 무엇을 근거로 확인했는가? |
| 후속 공정 | 어떤 확인이 끝나야 넘길 수 있는가? |

3. “공정이 급하다”는 조건이 붙어도 유지해야 할 인계 조건은 무엇인가?
