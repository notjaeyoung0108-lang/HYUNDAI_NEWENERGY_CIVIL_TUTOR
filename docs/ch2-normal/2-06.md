# 2-06. 배관 검사와 토목 인계의 접점

## ① Flow 도식
```text
지지대·관통부 인계 → 승인 재료·절차 확인 → 배관 설치·용접 → 검사 → 승인된 보수 → 재검사 → 시운전 인계
```

## ② 왜 이 순서인가
토목 담당자는 용접 판정 권한을 대신하지 않는다. 배관 지지대, 매입판, 관통부, 작업공간과 후속 마감 인계조건을 조정한다. 용접 불합격률은 현황 지표이고 개별 결함 합격 판정은 적용 기준과 검사 절차에 따른다.

## ③ Hold Point
용접·배관 담당자의 검사 승인 전 해당 후속 은폐·인계 보류, 승인된 보수 후 재검사

## ④ 정상 판정 기준
적용 설계·검사 기준을 충족한 개별 용접부와 시스템 인계 조건이 확인된다.

## ⑤ 다음 공종에 넘기는 것
용접·검사 맵, 부적합 위치, 재검사 결과, 지지대·관통부 미결 목록

## ⑥ 이상의 신호와 그 의미
예상 불합격률 4%는 이미 합격했다는 증거가 아니다. 전량 교체 공사량과 예상 보수량을 섞지 않는다.

| 확인 축 | 스스로 물어볼 질문 |
|---|---|
| 실물 | 도면·규격과 실제 상태가 같은가? |
| 기록 | 누가 무엇을 근거로 확인했는가? |
| 후속 공정 | 어떤 확인이 끝나야 넘길 수 있는가? |
