# 2-05. 원전 자재의 검수·추적·격리

## ① Flow 도식
```text
구매규격 → 공급자·서류 확인 → 인수검사 → 식별·보관 → 출고 승인 → 설치 이력 → 인계
```

## ② 왜 이 순서인가
서류가 실물과 연결되어야 추적할 수 있다. 규격, 로트·일련번호, 시험기록과 보관상태를 대조한다. 부적합 물품은 정상품과 혼용되지 않도록 식별하고 사용을 보류한다.

## ③ Hold Point
입고 적합성 확인 전 출고 금지, 부적합 처분 승인 및 재검사 전 설치 보류

## ④ 정상 판정 기준
구매요구와 검사결과가 일치하고 설치 위치까지 자재 이력이 이어진다.

## ⑤ 다음 공종에 넘기는 것
인수검사서, 자재 식별대장, 보관·출고 이력, NCR과 처분 결과

## ⑥ 이상의 신호와 그 의미
검사서 서명 후 하자를 발견해도 사용 보류가 필요하다. 서명은 실물의 결함을 없애지 않는다.

| 확인 축 | 스스로 물어볼 질문 |
|---|---|
| 실물 | 도면·규격과 실제 상태가 같은가? |
| 기록 | 누가 무엇을 근거로 확인했는가? |
| 후속 공정 | 어떤 확인이 끝나야 넘길 수 있는가? |
