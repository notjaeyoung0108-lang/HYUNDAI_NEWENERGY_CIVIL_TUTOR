# 18. 자재와 공정을 잇다

> **지난 장면** 17강에서 커플러 재고 7,000 ea를 안전 조치, 주공정, 여유 있는 공종 순으로 나누고 의사결정 기록을 남겼다. 그런데 P6 공정표에는 커플러 Lot 3이 어디에도 없었다.

## 공정표에 없는 일

17강의 결정 기록을 받은 공정 담당이 P6를 연다. 원자로건물 기초 WBS 아래에는 버림 콘크리트, 철근, 매입물, 타설만 있다. 07강에서 만든 **Activity**는 모두 현장에서 손으로 하는 일이다. 철근과 커플러는 공정표 밖에서 제때 도착한다고 가정돼 있었다. 그래서 공급사 공장이 침수됐을 때 공정표는 아무 신호도 보내지 않았다.

공정 담당이 WBS에 "조달" 노드를 하나 만들고, 커플러 Lot 3의 흐름을 Activity로 넣는다. 저녁에 신입 기사가 받은 출력물은 이렇다.

| Activity ID | Activity Name | 원기간 | 선행 | 관계 | TF 변경 전 | TF 변경 후 |
|---|---|---|---|---|---|---|
| U1-RB-PRC-2010 | 커플러 MR 발행 | 5d | - | - | 완료 | 완료 |
| U1-RB-PRC-2020 | 커플러 PO 발행 | 10d | PRC-2010 | FS | 완료 | 완료 |
| U1-RB-PRC-2030 | Lot 3 제작·출하 | 45d → 105d | PRC-2020 | FS | 70d | 10d |
| U1-RB-PRC-2040 | Lot 3 운송·인수검사 | 5d | PRC-2030 | FS | 70d | 10d |
| U1-RB-PRC-2050 | ROS 커플러 Lot 3 (마일스톤) | 0d | PRC-2040 | FS | 70d | 10d |
| U1-RB-FDN-1110 | 기초 매트 2차 리프트 철근 | 20d | PRC-2050 | FS | 10d | 10d |

제작·출하 기간을 공급사 공문대로 60일 늘렸다. 계산을 다시 돌리자 조달 줄의 **총여유**가 이렇게 바뀐다.

```text
변경 전 TF   70d
지연         105d − 45d = 60d
변경 후 TF   70d − 60d = 10d
```

조달 경로의 여유 70일 중 60일이 사라졌다. 아직 0이 아니므로 First Concrete나 준공은 늦어지지 않는다. 하지만 이 경로는 이제 여유 10일짜리 **준주공정**이다. 공급사가 열흘 넘게 더 늦으면 1110이 밀리고, 그 뒤로 이어진 기초 매트 공정 전체가 같이 밀린다. 조달을 공정표에 넣지 않았다면 이 여유가 줄어드는 것을 아무도 몰랐을 것이다.

::: term 조달 Activity | Procurement Activity | - | 조달 공정
자재청구, 구매주문, 제작, 검사, 운송, 인수검사처럼 자재를 현장에 들여오기까지의 단계를 공정표에 넣은 Activity. 시공 Activity와 관계로 이어 두면 공급사 지연이 공정표의 여유와 주공정에 바로 반영된다.
EN: "Procurement activities for long-lead items are logic-linked to the installation activities."
:::

<details><summary>❓ 먼저 생각해 보기 — 1110의 TF는 왜 변경 전후 모두 10d로 같을까?</summary>

변경 전에는 1110의 시작을 정한 것이 조달 줄이 아니라 다른 선행 작업(기초 매트 1차 리프트 쪽)이었다. 조달 줄은 70일이나 일찍 끝나서 1110에 영향이 없었다. 60일 늦어진 뒤에야 조달 줄이 1110의 시작과 맞물리게 됐지만, 아직 1110을 밀지는 않는다. 그래서 1110 자체의 여유는 그대로이고, 조달 줄의 여유만 1110과 같은 10일로 줄었다. 여유가 같아졌다는 것은 이제 두 경로가 함께 1110을 정한다는 뜻이다.
</details>

## 필요일을 거꾸로 센다

표의 2050은 기간이 0인 마일스톤이다. 이름의 ROS는 커플러가 인수검사까지 마치고 현장에서 쓸 준비가 돼야 하는 날을 가리킨다. 이 날짜는 공급사가 정하지 않는다. 1110이 시작해야 하는 날에서 거꾸로 센다. 인수검사 날수와 운송 날수를 빼면 공급사의 출하 기한이 나오고, 거기서 제작 기간을 빼면 PO를 내야 하는 마지막 날이 나온다. 13강의 청구서에 적은 "필요일"이 바로 이 날이다.

::: term 현장 필요일 | Required-on-site Date | ROS | 로스 일자, 현장 도착일
자재가 인수검사를 마치고 설치에 쓸 수 있도록 현장에 있어야 하는 날짜. 그 자재를 쓰는 시공 Activity의 시작일에서 인수검사·보관 준비 기간을 빼서 정한다. 구매주문 납기와 납기 독촉의 기준이 된다.
EN: "The ROS date for coupler Lot 3 is driven by the start of U1-RB-FDN-1110."
:::

## 공정표의 숫자로 재고를 미리 본다

공정표에 조달이 들어가자 한 가지가 더 가능해진다. P6의 각 Activity가 언제 커플러를 몇 개 쓰는지 알면, 달마다 얼마가 필요한지 미리 셀 수 있다. 자재 담당이 17강의 안 1 배분에 P6에서 뽑은 원자로건물 2차 리프트 소요를 더해 표를 만든다.

```text
D41 커플러 소요계획 (단위 ea)       M4       M5       M6       M7
  총소요 (P6 Activity 합)       4,000    3,000    7,000    3,000
    내역: M4 = B 1,000 + A 3,000 / M5 = A 3,000
          M6 = C 3,000 + RB 2차 리프트 4,000 / M7 = RB 2차 리프트 3,000
  기초재고                       7,000    3,000        0    1,000
  예정입고 (Lot 3)                   0        0    8,000        0
  기말재고 = 기초 + 입고 − 총소요
                                 3,000        0    1,000   −2,000
  순소요 (부족분)                    0        0        0    2,000
```

M7에 2,000 ea가 모자란다. 공급사 리드타임을 2개월로 보면 M5 안에 추가 주문을 내야 M7에 받을 수 있다. 계산은 이렇다. M7 − 2개월 = M5. 지금 자재 담당이 이 표를 보지 않았다면 M7에 또 요청서 세 장을 받았을 것이다.

::: term 자재 소요계획 | Material Requirements Planning | MRP | 자재 소요 계산
공정표가 정한 일정별 총소요에서 현재 재고와 예정입고를 빼 기간별 순소요(부족분)를 구하고, 리드타임만큼 앞당겨 주문 시점을 정하는 방법. 공정이 바뀌면 다시 계산한다.
EN: "The MRP run shows a net requirement of 2,000 couplers in month 7."
:::

## 세 개의 시스템이 하나의 숫자를 본다

위 표의 숫자는 세 곳에서 온다. 총소요는 P6에서, 기초재고와 예정입고는 회사 전사 시스템에서, 설치 위치별 수량은 모델에서 온다.

```text
P6 (공정)          언제 쓰는가  ─┐
                                 ├─►  MRP 계산  ─►  추가 MR / PO
ERP (구매·재고·원가) 얼마 있는가 ─┤
BIM 모델 (11강)    어디에 쓰는가 ─┘
```

::: term 전사적 자원관리 | Enterprise Resource Planning | ERP | 이알피
구매, 재고, 회계, 원가 같은 회사 업무를 하나의 데이터베이스로 묶어 관리하는 시스템. 현장에서 PO 발행, 입고, 불출을 입력하면 재고와 원가가 함께 갱신된다. 16강의 불출 대장도 결국 ERP의 거래 기록이 된다.
EN: "Goods receipt is posted in the ERP only after receiving inspection is accepted."
:::

실제로는: 현대건설은 소프트웨어 회사 이엔지소프트와 함께 **BIM** 기반 "스마트 공사관리 플랫폼(SCMP)"을 공동 개발했다고 2022년에 보도됐다. 3D 모델에서 자재 수량을 산출하고, 자재의 위치와 현황을 모바일로 추적하는 방식이다. 보도에 따르면 첫 단계는 프리캐스트 콘크리트(PC) 공사 자재관리에 맞춰졌고 물류센터 현장 등에 적용됐다. 원전 현장 적용 여부는 공개 자료로 확인되지 않는다. 출처: https://economist.co.kr/article/view/ecn202206290031

::: term 스마트 공사관리 플랫폼 | Smart Construction Management Platform | SCMP | -
현대건설이 이엔지소프트와 공동 개발한 BIM 기반 자재관리 플랫폼(2022년 보도). 3D 모델로 자재 물량을 산출하고 자재 위치·현황을 모바일로 추적·관리한다. 이 교재의 가상 현장에서는 같은 개념의 도구를 쓴다고 가정한다.
EN: "Material location and quantities are tracked on mobile devices through the BIM-based platform."
:::

## 확인 문제

<details><summary>1. 조달 Activity를 공정표에 넣으면 무엇을 볼 수 있게 되는가? 이번 강의 숫자로 설명하라.</summary>

공급사 지연이 공정표의 여유와 주공정에 미치는 영향을 바로 볼 수 있다. 커플러 Lot 3 제작 기간이 45d에서 105d로 60d 늘자, 조달 경로의 총여유가 70d − 60d = 10d로 줄어 준주공정이 됐다. 조달이 공정표 밖에 있었다면 이 변화를 알 수 없었다.
</details>

<details><summary>2. ROS 날짜는 누가, 무엇을 기준으로 정하는가?</summary>

현장(공정·자재 담당)이 그 자재를 쓰는 시공 Activity의 시작일에서 인수검사·보관 준비 기간을 거꾸로 빼서 정한다. 공급사가 정하는 날이 아니며, 구매주문 납기와 납기 독촉의 기준이 된다.
</details>

<details><summary>3. M6 기초재고 0 ea, 예정입고 8,000 ea, 총소요 7,000 ea, M7 총소요 3,000 ea일 때 M7의 순소요와 리드타임 2개월 기준 주문 시점을 구하라.</summary>

M6 기말 = 0 ea + 8,000 ea − 7,000 ea = 1,000 ea. M7 기말 = 1,000 ea − 3,000 ea = −2,000 ea → 순소요 2,000 ea. 주문 시점 = M7 − 2개월 = M5.
</details>

<details><summary>4. 15강의 추적 경로에서 히트 번호는 어떤 문서와 기록들을 잇는가? (15강)</summary>

제강사의 용해 단위(히트) → 재료시험성적서(CMTR)의 시험값 → 묶음 꼬리표 → 인수검사 기록 → 불출 기록 → 설치 위치(Activity)로 이어진다. 히트 번호가 이 고리 전체를 하나로 묶는다.
</details>

<details><summary>5. 08강 표에서 상부 철근(1030)은 하부 철근(1020)과 SS+5로 이어졌다. 이 관계는 무엇을 뜻하는가? (08강)</summary>

하부 철근 배근이 시작하고 5일이 지나면 상부 철근 배근을 시작할 수 있다는 뜻이다. 하부 철근이 일정 구역을 먼저 깔면 그 구역부터 상부 철근이 따라 들어가는 작업 방식을 나타낸다.
</details>
