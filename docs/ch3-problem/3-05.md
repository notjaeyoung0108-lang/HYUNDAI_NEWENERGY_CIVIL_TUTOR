# 3-05. 보조건물 외벽 — 단면재생과 탄소섬유 보강

## ① 상황과 출처
이벤트_기출문제.pdf **PDF 18쪽 NewEnergy** 요약. 준비 10분, 발표 5분, 질의응답 10분이다. 공식 정답이 아닌 계산·판단 해설이다.

## ② 제공된 자료
900㎡ 중 15%가 깊은 손상이며 보수 깊이 평균 30mm다. 단면재생 모르타르 20만원/㎥, 작업속도 60㎡/일, 양생 3일은 중첩할 수 없다. 탄소섬유는 35만원/㎡, 작업속도 90㎡/일이며 추가조건에 따라 총공기=면적/속도+1일이다. 여유 3일, L/D 1,000만원/일, 예산 4,000만원이다. 검사비는 각각 200·300만원, 불합격률은 2%·0.5%, 불합격 시 재시공비는 300·500만원과 추가 1일이다.

## ③ 먼저 답해볼 것
1. 보수면적과 체적, 각 안의 총공기를 구하라.
2. 불합격 때 추가 1일은 양안에서 같은 L/D를 만드는가?
3. 빠른 보강공법이 깊은 단면 결손의 복구를 대체할 수 있는가?

## ④ 무엇이 깨졌는가 — 단위와 공기부터
```text
면적 = 900 × 0.15 = 135㎡
깊이 = 30mm = 0.03m
체적(①) = 135 × 0.03 = 4.05㎥
```

| 항목 | 단면재생 | 탄소섬유 |
|---|---|---|
| 재료비 | 4.05×20 = 81만원 | 135×35 = 4,725만원 |
| 작업·양생 총공기 | 135/60+3 = 5.25일 | 135/90+1 = 2.5일 |
| 여유 초과 | 2.25일 | 0일 |
| L/D | 2,250만원 | 0만원 |
| 검사비 | 200만원 | 300만원 |
| 기본 합계 | **2,531만원** | **5,025만원** |

원문 식에 맞춰 소수일 비례 계산했다. 탄소섬유는 표의 양생 2일을 다시 더하지 않는다. 추가조건이 총공기=작업+1일이라고 정한다. 5mm 수지층은 단면재생 30mm를 대체하는 보수체적이 아니며, 별도 수지 단가는 제시되지 않았다.

## 불합격 위험의 기대비용
단면재생은 이미 여유를 초과했으므로 불합격 추가 1일이 전부 L/D다. 기대 추가비용은 0.02×(300+1,000)=**26만원**, 합계 **2,557만원**이다.

탄소섬유는 기본 2.5일에 추가 1일이면 3.5일이다. 여유 3일을 넘는 **0.5일만** L/D다. 기대 추가비용은 0.005×(500+500)=**5만원**, 합계 **5,030만원**이다. 기대값은 실제 지출 보장액이 아니다.

| 민감도 | 단면재생 | 탄소섬유 |
|---|---|---|
| 불합격 1회 실제 발생 비용 | 2,531+300+1,000 = 3,831만원 | 5,025+500+500 = 6,025만원 |
| 작업일을 정수로 올림하는 별도 가정 | 3+3=6일 | 2+1=3일 |
| 정수일 기본비용 | 81+200+3,000 = 3,281만원 | 4,725+300 = 5,025만원 |

정수 작업일을 적용하면 재시공 1회 발생 시 단면재생은 4,581만원으로 예산을 넘는다. 그래서 소수일·정수일 계약 정산과 작업일 운영을 확인해야 한다. 제시되지 않은 노무·장비·손상부 제거·추가 바탕 복구비는 표의 합계에 포함되어 있지 않다.

## ⑤ 공사 담당자라면
손상 면적·깊이·두께 부족과 원인을 실측하고 설계·품질 담당자에게 구조 영향을 확인한다. 보수재 시공 전에 손상부 제거와 바탕·철근 상태를 검사한다. 탄소섬유 시트를 붙이기만 하면 부족한 단면이 복구된다고 판단하지 않는다.

## ⑥ 공무 담당자라면
수량산출서와 보수 견적, 후속 공정 2.25일 영향, 검사·재시공 위험을 같은 비교표에 남긴다. 단면재생은 제시 항목 기준 예산 내이지만 공기를 충족하지 못한다. 탄소섬유는 기본비만으로도 예산을 1,025만원 초과한다.

## ⑦ 합의해야 할 것
**단면재생안을 우선 기술 검토하되, 현재 조건에서 품질·예산·무지연을 모두 충족하는 안은 확인되지 않았다**고 보고한다. 기술팀은 단면 복구와 보강 동등성을 검증하고, 공정팀은 후속공정 영향·인계 범위를 확인하며, 사업관리팀은 예산·일정 조정의 승인 주체를 정한다.

탄소섬유는 설계 적합성 및 필요한 선행 바탕 복구를 포함한 전체 공기·비용이 확인되고 예산 승인을 받아야 후보가 된다. 주어진 계산에서는 빠르지만 기술 적합성을 비용표만으로 승인하지 않는다. 문제에 없는 공기단축 효과를 확정값으로 만들지 않는다.

## ⑧ 부족한 정보와 꼬리질문
남은 85% 손상의 보수 범위, 실제 손상깊이 분포, 노무·장비 포함 단가인지, 검사기준, 양생 조건과 L/D의 일수 정산이 빠져 있다. 원문은 25mm 이상과 >25mm를 혼용하므로 경계부는 실측·판정기준을 확인한다.

## ⑨ 흔한 오답
- 135㎡를 135㎥로 사용: 깊이 환산 누락이다.
- 탄소섬유 양생 2일을 추가로 합산: 추가조건의 총공기식을 무시했다.
- 양안에 불합격 추가 L/D 1일을 동일 반영: 탄소섬유의 잔여 여유 0.5일을 놓쳤다.
- 단면재생은 싸므로 조건 모두 충족: 공기 2.25일 초과를 숨겼다.
- 시트가 강하니 단면 결손을 덮어도 된다: 바탕과 구조 적합성 검토가 빠졌다.

## 5분 발표의 뼈대
“보수면적은 135㎡, 체적은 4.05㎥입니다. 단면재생은 5.25일·2,531만원, 탄소섬유는 2.5일·5,025만원입니다. 전자는 일정, 후자는 예산 문제가 남습니다. 단면 복구 적합성을 우선 확인하고 공정·예산의 미충족 조건을 명시하여 조정 결정을 받겠습니다.”
