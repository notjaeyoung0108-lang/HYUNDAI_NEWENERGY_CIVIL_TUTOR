# 3-04. 배관 불합격 11% — 무엇을 몇 개 다시 용접하는가

## ① 상황과 출처
이벤트_기출문제.pdf **PDF 17쪽 NewEnergy** 요약. 준비 10분, 발표 5분, 질의응답 10분이다. 원문은 작업 범위 해석이 모호하며 아래는 공식 정답이 아니다.

## ② 제공된 자료
기존 용접부 100개 중 불합격 11개, 기존 보수 200만원/개, 작업 4일이다. 변경안 총 용접부 110개, 용접비 400만원/개, 예상 불합격률 4%다. 자재비 증분은 2,000만원, RT 검사 10만원/개, 하루 최대 보수·검사량 3개소, 여유 3일, 지연손실 1,000만원/일이다. 야간작업은 승인되지 않았다. 장래 50억원 용역 제안은 확정 이익이 아니다.

## ③ 먼저 답해볼 것
1. 공란 ①이 전체 신규 용접량인지 예상 보수량인지 확인하라.
2. 예상값 4.4개와 실제 작업계획의 정수 개수를 구별하라.
3. 기존안의 재불합격률이 미지수일 때 어떤 결론까지 가능한가?

## ④ 무엇이 깨졌는가 — 해석을 밝히고 계산한다
**해석 A: 예상 불합격부 보수량만 비교하는 문제 모형.** ①은 110×4%=**4.4개(기대값)**다. 실제 계획용으로 올림하면 5개다. 이는 최대 불량 수량을 보장하는 수가 아니다. 정수 작업일을 올림하면 ②는 ceil(5/3)=**2일**이다.

| 항목(만원) | 기존안: 11개 보수 | 변경안: 5개 보수 가정 |
|---|---|---|
| 자재 증분 | 0 | 2,000 |
| 보수 용접 | 11×200 = 2,200 | 5×400 = 2,000 |
| RT | 11×10 = 110 | 5×10 = 50 |
| 공기 | 4일 | 2일 |
| L/D | (4−3)×1,000 = 1,000 | 0 |
| 합계 | **3,310** | **4,050** |

연속량 기대값으로 계산하면 변경안은 2,000+4.4×400+4.4×10=**3,804만원**, 작업량/속도는 4.4/3=약 1.47일이다. 정수 계획과 섞지 않는다. 원문 기존안 4일은 11/3을 올림한 값이므로 주 비교표도 정수 일정을 사용했다.

**해석 B: 합금 배관 전체를 교체하여 110개 신규 용접이 필요한 경우.** 공란 ①은 110개이며 4%는 그 이후의 예상 재보수다. 신규 용접에도 3개/일이 적용된다고 가정할 때 초기 공기는 ceil(110/3)=37일, 초기 비용은 2,000+44,000+1,100+34,000=**81,100만원**이다. 추가 보수·철거·반입 일정은 별도다. 3개/일은 원문상 보수·검사 생산성이므로 신규 시공에 적용할 수 있는지도 확인해야 한다.

따라서 “4.4개만 용접하면 배관 전체 교체가 끝난다”는 결론을 내려서는 안 된다. 변경 대상이 일부 구간이면 그 구간의 실제 신규 용접 개수를 다시 받아야 한다.

## ⑤ 공사 담당자라면
품질팀·배관 담당자와 불합격 위치, 결함 유형, 승인된 보수 절차를 확정한다. 토목 담당자는 지지대·관통부·작업공간·마감 인계 영향을 조정한다. 승인되지 않은 야간작업으로 공기 2일을 회복한다고 가정하지 않는다.

## ⑥ 공무 담당자라면
재료비 1억원을 양안에 중복 반영하지 않고 증가분만 계산한다. 추가 예산 불가와 필수 품질 조치가 충돌하므로 비용 비교표를 근거로 예산 조정 결정을 상신한다. 미래 용역 50억원을 오늘의 보수비에서 빼지 않는다.

## ⑦ 합의해야 할 것
우선 기존 불합격 11개에 대한 승인된 보수·재검사를 준비하면서 변경 범위를 명확히 한다. 해석 A에서는 변경안이 740만원 더 비싸지만 일정상 유리하다. 그러나 원문은 L/D 발생 시 장래 입찰 점수 손실까지 가정하므로 직접비 최저안만으로 최종 선택할 수 없다. 변경안의 기술 적합성·전체 작업량·일정이 확인되면 장기 영향을 포함해 승인권자가 비교 결정한다.

해석 B라면 단축안이라는 전제부터 성립하지 않는다. 기존안은 1일 지연 및 재불합격 위험이 남으므로 그 한계도 함께 보고한다. 어떤 안도 모든 조건을 충족하지 못하면 이를 명시하고 예산·인계일의 조정 결정을 요청한다.

## ⑧ 부족한 정보와 꼬리질문
변경 구간 길이, 신규 용접량, 검사범위, 재료 승인·납기, 기존안 재불합격 가능성, 신규 작업 생산성이 필요하다. **총 불합격률 5% 이하라는 관리지표가 개별 불합격 용접부의 사용 승인을 뜻하지 않는다.**

## ⑨ 흔한 오답
- 110×4%=4개로 버림: 예상값·계획량을 혼동했다.
- 신규 용접 110개를 빼고 전량 교체 완료를 주장: 작업범위 누락이다.
- 기존안이 3,310만원이므로 무조건 선택: 입찰 영향과 재검사 불확실성을 무시했다.
- 승인 없는 야간작업 반영: 명시 조건을 위반했다.

## 5분 발표의 뼈대
“먼저 공란의 작업범위를 확인하겠습니다. 예상 보수량 모형이면 4.4개이고 5개·2일로 계획할 수 있으며 4,050만원입니다. 기존안은 4일·3,310만원이지만 입찰 영향이 남습니다. 전량 교체라면 110개 신규 용접을 포함해야 하므로 같은 단축 결론을 낼 수 없습니다.”
