# 3-02. H자재 3개월치를 세 부서에 나눠야 한다

## ① 상황과 출처
이벤트_기출문제.pdf **PDF 15쪽 NewEnergy**의 조건을 요약했다. 준비 20분, 발표 5분, 질의응답 15분이다. 공식 정답이 아닌 비교 해설이다.

## ② 제공된 자료
4차 입고는 3개월치이며 기존 재고는 없다. 5차는 3개월 뒤다. A는 주공정 작업 3개월치가 필요하고 지연손실 2억원/일이다. B는 안전 시정 구조물에 1개월치가 필요하며 1개월 뒤 점검 전 완료해야 한다. C는 2개월치를 동시에 받아야 착수하며 1개월 내 완료 계약이다. 미착수 시 위약금 100억원이고 장래 공사 규모는 200억원이다.

## ③ 먼저 답해볼 것
1. 안전 필수 수요를 확보한 뒤 남는 자재는 얼마인가?
2. A에 2개월치를 주면 지연이 1개월인가, 3개월인가?
3. C의 납기조건이 주어진 생산성으로 성립하는가?

## ④ 무엇이 깨졌는가 — 수량과 시간을 분리한다
검수된 재고 3개월치와 총수요 6개월치가 맞지 않는다. **B에 1개월치를 우선 배정**하고 남은 2개월치의 배분을 비교한다. 1개월=30일을 교육용 계산 가정으로 둔다.

```text
B 1 + A 2:
B: 월0 → 월1 완료
A: 월0~2 작업 → 월2~3 대기 → 5차 입고 후 월3~4 작업
A 기준 완료 월3, 실제 월4 → 1개월(30일) 지연
C: 착수 최소량 부족 → 미착수 위약금
```

| 배분(A/B/C, 개월치) | A 지연손실 | C 미착수 위약금 | 확인 가능한 손실 |
|---|---|---|---|
| 2 / 1 / 0 | 30×2 = 60억원 | 100억원 | 160억원 |
| 0 / 1 / 2 | 90×2 = 180억원 | 착수는 가능하나 완료 조건 별도 | 최소 180억원 |
| 1 / 1 / 1 | 60×2 = 120억원 | 100억원 | 220억원 |

둘째 안에서 A는 월3에 시작해 월6에 끝나므로 3개월 지연이다. 셋째 안에서 C의 1개월치는 착수에 쓰이지 못한다. 이 표는 5차 납품에 A의 잔량이 포함되고 A가 물량에 비례해 작업할 수 있다는 가정이다.

**원문 조건의 충돌:** “기준 작업기간=H자재 소요물량 기간”이면 C의 2개월치 작업은 2개월이다. 자재 전량을 줘도 1개월 완료를 보장할 수 없다. C가 원래 병렬작업으로 수행하는지, 추가 자원 투입이 허용되는지 확인해야 한다. 이를 숨기고 C 성공을 확정하지 않는다.

## ⑤ 공사 담당자라면
B의 구조물 설치·검사까지 월1 안에 끝나는 작업계획을 확보한다. A는 먼저 받은 2개월치로 어느 작업까지 할 수 있는지 구획·순서·인계를 확인한다. 자재만 배정하고 실제 작업 가능성을 확인하지 않으면 예상한 손실이 더 커질 수 있다.

## ⑥ 공무 담당자라면
A의 부분 작업과 후속입고 보장, C 미착수 통지 및 위약금 조건을 기록한다. 160억원은 이 문제의 정량 손실이고 실제 계약상 책임 판단을 대신하지 않는다. 장래 200억원은 매출 규모로서 이익률·수주확률이 없으므로 손실에서 200억원을 빼지 않는다.

## ⑦ 합의해야 할 것
주어진 조건에서는 B 1·A 2를 우선 제안한다. 안전 시정을 확보하고, 비교 가능한 손실이 가장 작으며 A 핵심공정 지연도 상대적으로 작다. C의 불가능한 납기 조건과 계약 해소 방안은 의사결정권자·발주처에게 즉시 공유한다. 문제에 없는 긴급 구매를 기정사실로 더하지 않는다.

## ⑧ 부족한 정보와 꼬리질문
달력상 실제 일수, A 부분작업 가능성, 5차 물량·도착일, C 병렬작업 허용 여부, B 설치 검사 소요시간을 확인한다. “C가 장래 200억원 공사를 준다면?”에는 확정 이익·현재 손실·안전 의무를 구별한다고 답한다.

## ⑨ 흔한 오답
- 모든 부서에 1개월치씩 배분: C는 착수하지 못한다.
- A에 2개월치를 주고도 3개월 지연 산정: 선행 작업 실적을 무시했다.
- 안전 미시행을 과징금만 내는 선택으로 취급: 필수 제약을 빠뜨렸다.
- C 2개월 물량을 1개월에 완료한다고 단정: 원문의 생산성 조건과 충돌한다.

## 5분 발표의 뼈대
“B 1개월치, A 2개월치를 우선 배정하겠습니다. 월별 작업표 기준 A는 30일 지연으로 60억원, C 미착수는 100억원이어서 확인 가능한 손실은 160억원입니다. C에 전량을 주는 안은 최소 180억원이며 1개월 납기 성립도 확인되지 않았습니다.”
