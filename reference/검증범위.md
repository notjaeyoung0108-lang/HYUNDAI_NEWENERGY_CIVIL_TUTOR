# 출처와 검증 범위

## 기출 자료

사용자 제공 이벤트_기출문제.pdf의 PDF 14~18쪽을 직접 확인했다. 공식 정답은 제공되지 않았다. 원문 5쪽의 렌더 이미지와 추출 텍스트를 함께 보관했다. 페이지별 연결은 14→Q14-1·Q14-2, 15→Q15, 16→Q16, 17→Q17, 18→Q18(docs/chN/Q*.md)이다.

## 기술 원리 참고

- [NRC — Nonconforming Materials, Parts, or Components](https://www.nrc.gov/facilities-safety/new-reactors/how-we-regulate/regulatory-oversight/quality-assurance-for-new-reactors/10-cfr-50-appendix-b-non-and-nov-and-10-cfr-part-21-novs/nonconforming-materials-parts-or-components): 부적합 자재·부품 관리가 독립된 품질보증 항목임을 확인하는 자료다. 국내 현장의 적용 법령으로 인용하지 않았다.
- [NRC — Quality Assurance for New Reactors](https://www.nrc.gov/facilities-safety/new-reactors/how-we-regulate/regulatory-oversight/quality-assurance-for-new-reactors/regulations-standard-review-plan-secy-paper-and-nureg-1055): 원전 안전 관련 설비의 품질보증 체계 참고. 개별 프로젝트의 적용범위는 승인된 계약·설계·품질 문서로 확인해야 한다.
- [ACI 440.2R-17 공개 미리보기](https://www.concrete.org/Portals/0/Files/PDF/Previews/440.2R-17_preview.pdf): 외부 부착 FRP는 보수부와 기존 콘크리트를 포함한 바탕의 힘 전달 능력이 필요하다는 원리 참고. 최신 설계기준인 것으로 주장하지 않는다.
- [ACI 440.2-23 공개 미리보기](https://www.concrete.org/Portals/0/Files/PDF/Previews/440.2-23_preview.pdf): FRP 보강 설계·시공 가이드 참고. 전체 유료 본문이나 특정 설계의 적합성을 검증한 것은 아니다.

## 수행한 검증

공정 화살표는 PDF 14쪽 이미지를 판독했다. 모든 수치는 문제 모형의 단위·산술·시점 기준으로 검산한다. 계산 검증 스크립트와 브라우저 기능 검증은 기술 전문가의 개별 설계 검토를 대체하지 않는다. 안전계수·시공 허용오차·검사 수용기준은 임의로 추가하지 않았다.
