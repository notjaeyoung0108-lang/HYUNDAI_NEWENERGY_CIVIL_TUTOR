# 검증 기록

2026-10-07 작업 환경 기준. `tools/check-calculations.py`로 PDF 14쪽 이벤트 네트워크, 자재 배분 시간축, 배관 두 가지 해석, 콘크리트 체적·공기·비용·재시공 기대비를 검산했다.

`tools/browser-qa.py`는 설치된 Chrome의 실제 브라우저에서 다음을 확인한다.

- 20개 교재 화면과 5개 PT 화면 로드, 제목·본문 검색 및 빈 검색.
- 원문 이미지 로드, 해설 기본 접힘 및 펼침.
- 답안 HTML 문자열의 안전한 표시, 자동 저장과 새로고침 후 복원.
- 읽음·자기점검·암기 평가 저장, JSON 백업 내용.
- 타이머 시작·경과·일시정지, 잘못된 경로 복귀.
- 초기화 취소·확정, 저장소 손상·저장 차단 시 안내.
- 390px 모바일 화면의 교재·표·PT·암기·기록 가로 넘침 여부.
- JavaScript 런타임 오류 없음.

`desktop.png`, `mobile.png`는 검증용 임시 브라우저 기록을 포함한 화면이다. 실제 사용자의 기록은 아니다. 공개 배포나 현장 기술 승인 검증은 하지 않았다.
